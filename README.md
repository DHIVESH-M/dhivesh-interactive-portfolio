## 🛠️ Tech Stack

- **Core Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4 (Electric blue `#00f0ff` accent lighting, dark charcoal `#07080b` glassmorphism)
- **Animation & Scrubbing**: GSAP & ScrollTrigger
- **Icons**: Lucide Icons & Custom Bespoke SVG Assets
- **Audio Synthesizer**: Self-contained Web Audio API synthesizer (zero audio file downloads, mute toggle default)
- **Effects**: Canvas Confetti

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/DHIVESH-M/dhivesh-interactive-portfolio.git

# Enter project directory
cd dhivesh-interactive-portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
